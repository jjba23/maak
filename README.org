/King's Make: Lisp/Scheme command runner and control plane à la Make (Guile)/

If you like my work, please support me by [[https://bmc.link/jjbigorra][buying me a cup of coffee ☕]] so I can continue with a lot of motivation.

kmk has as core mission being your control center or command plane, and act as a command runner, not a build system, so it avoids much of Make's complexity. No need for .PHONY recipes here.

kmk uses Lisp (Guile Scheme) for everything  λ and as such, is not limited by the lack of expressiveness and power that you encounter when using certain tools and DSLs. Here we have a full programming language's power. This also means you don't need to learn yet another syntax or language, but can use Lisp and lambda-calculus skills here.

Have you ever found Makefile to be repetitive, lacking expressiveness and having a weird, limited syntax and unexpected behavior?

Fear not, *King's Make* is here 👑. With the full power of Scheme (Guile) directly in your command runner/control plane,  easily define functions, data, lists, loop through them, macros, etc.

--------

All you will need to do to use kmk is to write a file (by default ~./kmk.scm~) where you define your kmk file module and import kmk library:

#+begin_src scheme
(define-module (kmk)
  #:declarative? #t
  #:use-module (kmk kmk))
#+end_src

--------

* Defining tasks

#+begin_src scheme
;; Format Scheme source code files according to the Guix style guide
(define (fmt)
  (log-info "Format Scheme files using Guix Style")
  ($ '("find . -maxdepth 8 -name '*.scm'"
       "-type f -exec guix style -f {} \\;")
     #:verbose #t))

;; Display program help screen
(define (help)
  ($ '("guix shell -f guix.scm -- kmk --help")))

;; Default task run when no arguments are passed: do something fun
(define (default)
  (let* ((entries '(1 3 5 7 9))
         (arithmetics (lambda(x) (* x x 3)))
         (some-data (map arithmetics entries)))
    (log-info "Running default task")
    (log-info "Performed some fun arithmetics:\nResult: ~a" some-data)))
#+end_src

--------

* Help

You can see the help by invoking kmk with the ~--help~ argument or running ~guix shell -f guix.scm -- kmk help~.

* On Guix

kmk is Guix-first and caters to Guix as first-class citizen in favor of other package managers or build systems. kmk targets exclusively systems that can run Guile Scheme (and optionally Guix).
