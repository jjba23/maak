#+title: maak for Neovim

[[../../docs/editors.org][Editor integrations]]

The tasks of the nearest =maak.scm=, in a picker, with the arguments maak's
grammar allows, run in a terminal tab — or dry-run, printed instead of run.

* Requirements

- Neovim 0.9 or newer (for =vim.ui.select= and =vim.json=)
- Guile, which maak itself needs
- [[../bin/maak-tasks][=maak-tasks=]] on your =$PATH=, or its path in the configuration:
  #+begin_src shell
  install -m 755 contrib/bin/maak-tasks ~/.local/bin/maak-tasks
  #+end_src

* Install

With lazy.nvim, from a checkout of maak:

#+begin_src lua
{
  dir = "~/Hacking/maak/contrib/nvim",
  config = function()
    require("maak").setup({
      executable = "maak",       -- or a path
      helper = "maak-tasks",     -- or a path to contrib/bin/maak-tasks
    })
  end,
}
#+end_src

For a plain =runtimepath= install, copy or link this directory into
=~/.local/share/nvim/site/pack/*/start/= and call =require("maak").setup()=
where you configure your editor.

* Commands

| Command              | What it does                                               |
|----------------------+------------------------------------------------------------|
| =:Maak=              | Pick a task, answer its arguments, run it in a new tab.    |
| =:MaakDryRun=        | The same pick, with =maak -n=: the commands, not the run.   |
| =:MaakRun build -v=  | Run =build= with the words that follow, no prompts.        |
| =:MaakLast=          | Run the task last run here again, with the same words.     |
| =:MaakList=          | Put every task in the quickfix list, at its definition.    |
| =:MaakGoto=          | Pick a task and jump to the procedure that defines it.     |

=:MaakRun= completes task names as you type, from the same Maak file.  =:Maak=
and =:MaakGoto= use =vim.ui.select=, so a picker plugin that replaces it —
[[https://github.com/nvim-telescope/telescope.nvim][telescope]],
[[https://github.com/stevearc/dressing.nvim][dressing]] — is what you pick
with, without this plugin knowing about it.

* Arguments

The prompts follow the lambda list of the task, the way maak.el does:

- a required argument must be answered;
- an optional argument left blank is not passed at all, and neither is anything
  after it, so the task's own default applies;
- a rest argument takes any number of space separated words;
- a keyword argument is never asked for, because maak's command line cannot pass
  one.  A keyword argument with no default is an error, said before the run.

An argument that begins with a dash is set apart with =--=, as in
=maak quick-math -- -23 42=.
