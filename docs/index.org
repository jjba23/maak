procedure. The guide is split by topic; each page links onward where a topic
continues.

The everyday tools have modules of their own, so a Maak file can import just the
one it needs: [[file:git-and-archives.org][=(maak git)= and =(maak archive)=]],
[[file:containers.org][=(maak container)=]], [[file:niri.org][=(maak niri)=]] and
[[file:downloads.org][=(maak net)=]]. Every procedure has a matching =-argv=
builder where the command line has options worth inspecting; the builder is what
the procedure feeds to =run=, what =--dry-run= prints, and what a test can
assert without the tool installed.

Start with [[file:installation.org][installation]] and the
[[file:quick-start.org][quick start]] if you are new to the project, or go straight
to [[file:tasks.org][tasks]] if you already have a =maak.scm= to run.
