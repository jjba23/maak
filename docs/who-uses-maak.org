[[file:index.org][Documentation index]]

maak runs the automation of the forty-one projects below: their builds, their
releases, their checks and their sites.  The list leans towards Lisp, because
maak is a Guile program and a task list is a Scheme module, but nothing in it has
to be: the runner does not care what it starts.

The editor driving maak in those projects is usually Emacs, because
[[https://github.com/jjba23/maak.el][maak.el]] is the canonical front end.  The
other integrations in [[file:editors.org][Editors, shells and the REPL]] run the
same tasks, from the same =maak.scm=.

* Guile libraries and programs

- [[https://github.com/jjba23/araneola][Araneola]] — a web crawler and sitemap generator, written purely in Lisp.
- [[https://github.com/jjba23/bewaking][bewaking]] — authentication, authorisation and secure tokens in an expressive DSL.
- [[https://github.com/jjba23/ggg][GGG (Guile Glyph Generator)]] — SVG images, handy glyphs and Org/Markdown badges.
- [[https://github.com/jjba23/guile-openapi-generator][Guile OpenAPI Generator]] — turns an OpenAPI 3.x specification into Guile Scheme.
- [[https://github.com/jjba23/hygguile][Hygguile]] — a UI framework for cozy, professional interfaces, with the power of Scheme.
- [[https://codeberg.org/jjba23/kracht][kracht]] — utility methods and re-exports from Guile's standard library.
- [[https://github.com/jjba23/mutastructura][Mutastructura]] — schema and database migrations in raw SQL, powered by Lisp.
- [[https://github.com/jjba23/olive-css][Olive CSS]] — utility-class vanilla CSS in Tailwind's syntax, written in Lisp.
- [[https://codeberg.org/jjba23/orgwebalchemy][OrgWebAlchemy]] — parses Org-mode with a PEG grammar and renders HTML, Markdown or SXML.
- [[https://github.com/jjba23/scriba][scriba]] — structured logging: levelled, taggable and configurable.
- [[https://github.com/jjba23/sift][sift]] — a Lisp, Scheme and Emacs Lisp formatter and linter.
- [[https://codeberg.org/jjba23/sss][SSS (Supreme Sexp System)]] — a Lisp machine adventure where hacking culture is celebrated.
- [[https://github.com/jjba23/veritas][Veritas]] — unit, integration and black-box testing framework powered by Lisp.
- [[https://github.com/jjba23/iter-vitae][Iter Vitae]] — a résumé as code: the curriculum generator with a Lisp at its centre.
