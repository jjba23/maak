Usage: maak [OPTIONS] [-- [TASKS]... [TASK_ARGS]...]

Options:
    -f, --file FILE
        Specify the path to the Maak file (defaults to ./maak.scm).

    -h, --help
        Display this help message and exit.

    -l, --list
        List all available tasks in the currently loaded Maak file.

    -L, --load-path DIR
        Add DIR to Guile's load path, so a Maak file can require modules
        that live outside its own directory.  Repeat the flag, or separate
        several directories with ':' in one flag.  The directory of the
        Maak file, and the directories named by the MAAK_LOAD_PATH
        environment variable, are added automatically.

    -n, --dry-run
        Run in dry-run mode. Print shell commands instead of executing them.

    -q, --quiet
        Quiet mode. Suppress standard logging, banners, and header outputs.

    -v, --version
        Display the Maak version and exit.

    --debug
        Show the Guile backtrace on an error.  The same as setting the
        MAAK_DEBUG environment variable.

+----------------------------------------------------------------------------+

Examples:

    # Run the 'test' task
    maak test

    # Run 'test', then 'quick-math', passing arguments to the tasks
    maak quick-math -- 42 42

    # Run tasks from a specific file
    maak -f ./build/tasks.scm -- fmt,test

    # Quietly test run a pipeline without modifying files
    maak -n -q -- clean,build,deploy

    # Let the Maak file require modules from ./lib
    maak -L ./lib -- build
