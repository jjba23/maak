KMK - King's Make
    King's Make: Scheme Make-inspired automation tool with the power of Lisp

    See more at: https://codeberg.org/jjba23/kmk

Usage: kmk [OPTIONS] -- [TASKS]...
Options:
    -f, --file FILE
        Specify the Scheme config - path to KMK file (defaults to ./kmk.scm).
    -h, --help
        Display this help message and exit.
    -l, --list
        List all available tasks in the currently loaded KMK file.

+----------------------------------------------------------------------------+

Examples:

    kmk -- test

    kmk -f ./kmk.scm -- fmt,test,run
