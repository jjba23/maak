Usage: maak [OPTIONS] -- [TASKS]...
Options:
    -f, --file FILE
        Specify the Scheme config - path to Maak file (defaults to ./maak.scm).
    -h, --help
        Display this help message and exit.
    -l, --list
        List all available tasks in the currently loaded Maak file.

+----------------------------------------------------------------------------+

Examples:

    maak test

    maak test,quick-math 42 42 100

    maak -f ./maak.scm -- fmt,test,run
