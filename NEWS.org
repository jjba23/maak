All notable changes to this project are documented in this file, one section per
release tag. The version itself is written once, in =src/maak/version.scm=.

This project adheres loosely to [[https://semver.org/spec/v2.0.0.html][Semantic Versioning]].

Nothing yet.

*[Released]*

** v0.16.1 (2026-11-09)

A wording release: the list of projects keeps the projects and loses the
paragraph that counted them.

*** Changed

- The paragraph above the list is gone. The names, the groups and the closing
  invitation to send a link stay; nothing on the page now says how many
  projects there are, which is a number that was stale the moment it was
  written.

** v0.16.0 (2026-11-09)

The front page tells the truth about who this is for: the projects that run on
maak are listed as a scan of the tree finds them, not as memory had them.

*** Added

- Forty-one projects, in five groups — libraries and programs, programs with a
  life of their own, configurations and systems, editors, and sites — each with
  a line saying what it is and a link to where its repository lives. Thirty-five
  are on GitHub and six on Codeberg, which is what a scan of the checkouts, of
  =gh repo view= and of the two hosts says; the seven that were listed before
  were the ones that came to mind.

** v0.15.0 (2026-11-09)

A packaging release: the Arch recipe builds, a release keeps every copy of the
version in step, and two specs watch the things that used to rot in silence.

*** Added

- ~test/veritas/unit/version.scm~ compares every copy of the version — the RPM
  spec, the Arch recipe, the manual page, the installation page and the newest
  Debian changelog entry — with ~maak-version~, so a release whose copies were
  not rewritten fails the suite instead of shipping a package two versions old.
- ~test/veritas/unit/guide.scm~ resolves every ~file:~ link in the README, the
  news and the pages under ~docs/~, checks each ~::#anchor~ against the
  ~CUSTOM_ID~s of the page it points at, and checks that every page under
  ~docs/~ is linked from the index.
- The Arch page of the guide says how to build the package now, instead of
  asking for a patch.

*** Fixed

- ~packaging/arch/PKGBUILD~ unpacked into the wrong directory: ~makepkg~
  extracts the tag's archive as ~maak-VERSION~, and the recipe changed into
  ~maak~, so it could not have built at all. Its ~pkgver~ said 0.12.2 and its
  checksum was that archive's, and it fetched from a host the release tags are
  not pushed to.
- ~packaging/debian/changelog~ was six releases behind, at 0.8.3.

*** Changed

- ~maak sync-version~ writes the Arch ~pkgver~ as well, so the recipe follows a
  release like the RPM spec and the manual page do. The changelog entry and the
  Arch checksum stay in a person's hands, and
  [[file:docs/project.org::#releasing][the releasing page]] says why.

** v0.14.1 (2026-11-08)

A housekeeping release: the licence, the pipeline and the documentation are
brought in line with the sibling projects, and a release is no longer published
from a floppy disk.

*** Changed

- The project is licensed under the *MIT License*, the same terms as =ggg=,
  =iter-vitae=, =veritas= and =bewaking=. =COPYING= became =LICENSE=, every
  source, script, test and packaging file carries an
  =SPDX-License-Identifier: MIT= header, and the licence fields of the Nix
  derivation, the Guix package, the RPM spec, the PKGBUILD and the Debian
  copyright file all say MIT.
- =maak --version= prints =License: MIT=, so a script that reads that line sees
  the same answer the files give.
- The README is a landing page now: it leads with the point that a task is a λ,
  and the manual moved into =docs/=, one topic per page, indexed by
  =docs/index.org=. Every page keeps the text it had; only the headings moved.
- CI is a GitHub Actions workflow that calls the same Byggsteg pipeline the other
  projects use, so =.woodpecker/byggsteg.yaml= is gone.
- =maak sync-version= writes the version into =docs/installation.org= rather than
  the README, which no longer carries a copy of it.

*** Removed

- =resources/maak-icon.png=, the floppy-disk mascot, and the copy of it embedded
  in =resources/maak-banner.svg=. The banner keeps its terminal window, wordmark
  and prompt.

*** Added

- =NEWS.org=, this file.
